## 分かったこと

- ほぼ変わらない → 仮説は支持されない。本番には使わない
- 学習中の val loss を見ると、本当の原因は **過学習**：画像モデルは val loss が **1 epoch 目で最小**（手先 1.40・腕全体 1.34）で、100 epoch 後は 3.40・4.28。数値モデルも 20〜30 epoch で最小（0.82・0.88）、100 epoch 後は 1.60・2.19
